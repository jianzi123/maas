# 本轮学习手册重构说明

基线：5020d5c。修订日期：2026-11-05。本轮只改docs/performance；运行代码、共享协议、固定输入与所有实验执行开关保持原样。

## 为什么重做

旧入口以资料清单和命令为主，新成员难以判断先学什么、为什么这样算、怎样证明学会。入门页还指向旧分支，并将完整课程最低Python版本写得过低：锁定NumPy2.3.5的安装元数据要求Python>=3.11。

## 交付差异

| 旧问题 | 本轮改进 | 验证方式 |
|---|---|---|
| 入门/进阶混在参考资料里 | 两条明确路线，B01–B06和A01–A04 | 逐练习检查输入、输出、解释和边界 |
| 只列参数/技术名 | 八张目标卡，分K/R/E层 | 每卡列成熟baseline、触发证据、单因素、约束及淘汰条件 |
| 单算子收益容易跨层外推 | Amdahl手算与反推例，说明适用假设 | 执行教学计算，核对1.1429/1.5714等值 |
| 看测试数字当毕业 | 答案页与可解释交付标准 | 用原因和反例核对，不要求GPU |
| 执行手册重复概念 | 改成目标→冻结→运行→停止→证据的规程 | 本地链接与导航检查 |
| 未批准建议可能被当默认 | 文档目标登记表execution_enabled=false，所有实际阈值/结果为null | JSON结构及门槛状态核对 |

## 本轮验课与没有重做的工作

本轮已照文复验8个命令/代码片段：decode mask、报告计算、时钟反例、8组CPU参考、21个宿主finite场景、80次小规模loopback和Amdahl手算；59个本地链接有效。fixture线程全部退出。它们用于确认文档能照做，不是新增GPU或模型性能实验。

83项完整回归、21宿主场景及其范围保留为5020d5c阶段的既有证据。本轮是文档重构，不会把未重跑的完整套件写成新执行，也不声称CUDA编译、低精度、模型质量或平台优化通过。

本轮不作环境安装、模型/权重下载、真实平台/供应商/GPU调用，不改变成员已经确认的业务不变量。实际验课日志、源文档hash和离线阅读版随任务评论交付。
