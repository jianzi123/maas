# 约14分钟产品演示

本脚本用于 MAAS-21 的最终同版本安装包，复用现有控制台。没有真实模型凭据时，可以使用包内**明确命名的受控 profile**；正式产品会话仍须MySQL。旧 `agent-headless --state-dir`、浏览器 DevelopmentChat、Vite bridge 均不能代替本演示的正式入口。

## 准备

- 主负责人提供两份同版本包、源码SHA、镜像/迁移版本与SHA256；先按包内README实际命令启动。只使用独立 Compose project、卷和端口；不改他人服务。K8s写入另依实际授权。
- 使用包内明确的初始化管理员流程，密码经安全环境配置，不展示.env/Secret。确认管理和Chat共用一个Go/MySQL服务与同源Cookie/CSRF。
- 挂载同版本 console-config.json，明确RunLimits、币种、工具bounded_arithmetic@1和list_visible_models@1。受控样例TST只用于对应受控策略。
- 真实模型 profile 需要已批准端点/模型/凭据/额度及公开能力声明。tools-v1未具备时，只演示普通Chat与明确的Agent限制；不把任意文本模型硬标tools-v1。审批/慢流需对应策略/受控配置；不保证普通来源一定触发批准或能在短输出完成前点到停止。
- 开始记录实际 URL、Git/镜像/迁移/协议/工具版本、profile和模型别名。每步记录通过/失败/未执行及限制；本脚本本身不是执行证据。

| 时间 | 输入与操作 | 预期画面/验点 | 可用条件与失败处理 |
|---|---|---|---|
| 0:00–2:00 启动初始化 | 在解压包目录按README执行构建/启动/迁移；确认应用和MySQL健康，再登录控制台 | 同一站点显示模型、Key、发布、用量、Chat导航；初始化/迁移失败时不能故障放开 | 正式组合待最终安装验证。静态服务器ready不等于API/MySQL健康。保留包内实际命令与退出码 |
| 2:00–3:30 模型配置 | 在“模型发布”按已有配置入口提交获准ExternalAPI来源引用，查看generation/活动修订；进入模型目录 | 已提交、已部署、网关应用和可调用分开，capabilities与来源批准相符；Secret不进浏览器 | 没有来源/发布屏障时明确不可调用；记录具体缺口，不以受控demo冒充发布成功 |
| 3:30–4:30 普通Chat | 新建会话，选获准模型/普通Chat；提示词：`用两句中文解释什么是幂等，并给出一个🙂。` | 流式Markdown/代码显示，完成后多轮追加；记录原run与child IDs | 真实模型未授权则用明确受控profile，受控回答不要求遵循自然语言语义；失败/断流不伪装成功 |
| 4:30–6:30 安全工具 | 切Agent，提示词：`请调用 bounded_arithmetic，参数 {"a":6,"b":7,"op":"multiply"}，再调用 list_visible_models，参数 {}，最后总结。` | 步骤/工具名版本、参数、状态和结果可读；算术42，目录仅可信主体可见模型；实际attempt不补造 | 两个工具实现存在；是否由当前ModelClient选择/多步调度须最终同组合实测。受控模型固定策略可有固定调用，不把任意提示词当精确控制协议 |
| 6:30–7:30 批准 | 使用安装明确要求批准的安全计算策略，再发上述算术输入；核对参数摘要/版本/期限后点一次批准 | waiting_approval期间未执行；批准后按实际事件推进，拒绝/过期不可重新用同批准 | 默认安全工具不一定要求批准；无相应策略则标“本安装未配置，未执行”，不可为了演示凭空显示批准 |
| 7:30–8:30 停止 | 对已批准来源发长输出请求：`按1到200逐行输出，每行一句短说明。`；流式期间点击停止 | ACK显示取消已请求，等待服务端cancelled/limit_reached等权威终态；未知结果隔离，不出现未知操作重跑入口 | 输出太快可用明确受控慢流profile；不能声称停止ACK等于上游已取消或不计费 |
| 8:30–10:00 刷新/断线 | 记录当前run/child IDs；在活动Run点断开事件连接→只读重连，刷新页面；编辑原消息/重新生成只在显式点击时执行 | GET快照/事件恢复同一run，不增加生成POST；410丢整批页和旧after，稳定后完整重建；编辑追加关联记录 | 可通过独立98/100/102历史夹具补分页故障；注入结果单列，不冒充自然流量。ACK未知先核对原command |
| 10:00–12:00 应用/MySQL重启 | 仅对本演示独立project，按包内服务名重启应用，再重启MySQL，保留卷；重新登录/刷新同一会话 | 历史消息、步骤、工具结果/事件、原run/child与原消费保留，不二次调用模型；数据库不可用时明确拒绝 | 必须真实MySQL组合才能打勾。严禁 `down -v`、删除PVC或重启他人MySQL；恢复失败保留现场 |
| 12:00–14:00 用量核对 | 展开Chat“原请求/计量关联”，在请求用量页按同一child ID只读查回；比较重启前后记录 | known/inflight/held、aggregation_complete、币种/价表分别显示；未知actual不显示0；父run多child不当作一个子消费重复扣量 | Chat已有父/子关联展示，管理原ID查询已有入口；最终Go适配/SQL唯一结算实测单列，不以UI显示替代账本证据 |

## 自动化和记录

先执行 `npm test`、`npm run build`、`node scripts/deployed-build-browser.mjs`（后者仅生产静态产物＋HTTP夹具）。正式站点用 `scripts/deployed-smoke.mjs`；默认只读验证，启用生成必须显式设置开关且具备对应模型/额度批准。应用/MySQL重启只在主交付隔离环境执行，不由前端脚本擅自重启。

结束时交截图、实际操作结果、准确组合和未执行项。文件上传、shell、MCP、检索/长期记忆、子Agent/多Agent尚未实现，不演示空按钮或列为已完成。清理只停止本演示自有服务，保留需要移交的数据；无需长期运行时不留常驻进程。

本轮正式入口接点更新（MAAS-20 2026-11-23附件，尚待固定新Go SHA装配）：migrate/serve --config /etc/maas/product.json，MySQL-only，共享原管理登录；当前正常产品适配只有text-v1。故真实上游Agent工具演示、批准及多步工具调用应标“当前正式适配未装配/未执行”，直到独立、明确的MySQL受控profile或获准tools-v1适配到位。不能用原agentcontrolled文件会话替代本表第10分钟的MySQL重启步骤。普通Chat也须具备已发布Profile、平台Key预算、Higress/TLS/签票等真实输入，空models仅能登录/查历史。
